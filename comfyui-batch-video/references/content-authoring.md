# 从选题到提示词：内容生产规范

以前的做法是"在 ChatGPT 里写好提示词，再贴过来"。这一步现在可以直接在这里完成，
不必来回搬运。本文件规定怎么写、写完怎么校验。

## 一、最小输入：选题清单

只要有"中文标题 + 一句话知识点"就能开工：

```json
[
  {"id": 91, "title": "为什么猫会呼噜", "point": "猫呼噜时的振动可能有助于放松和恢复"},
  {"id": 92, "title": "为什么树叶秋天会变黄", "point": "叶绿素分解后，其他色素显现出来"}
]
```

我会把它扩写成六字段的提示词 JSON（`integrated / soundscape / music / voice / dialogue`），
字段含义见 `prompt-format.md`。

## 二、画面描述写法（英文）

固定骨架，四条缺一不可：

```
<主体 + 场景 + 动作> + Vertical 9:16 composition. One continuous shot.
0–2 seconds: <起始动作>
2–5 seconds: <知识点可视化动作>
<风格尾句>
```

- 主体要具体：`a cute little bat` 而不是 `an animal`
- 分镜用 `0–2 seconds:` / `2–5 seconds:`，注意是 en dash `–`
- 知识点靠"可视化动作"表达，不要靠旁白解释：写 `show glowing sound waves bouncing back`
  而不是 `explain how echolocation works`
- 风格尾句统一：`Cute high-quality 3D educational animation, bright colors, child-safe.`
- **画面描述里不要出现中文**

## 三、中文台词长度（最容易翻车）

模型要在一句话内说完，超了会被截断。经验值：

| 语速 | 5 秒可容纳 |
|---|---|
| 儿童科普旁白（偏快） | 约 22—26 字 |
| 正常 | 约 18—22 字 |
| 偏慢 | 约 15—18 字 |

**建议控制在 18—22 字**。写完后跑 `scripts/validate_prompts.py` 会自动标出超长的。

句式建议：`<现象/主体> + <原因/机制>`，一句话一个知识点，不加"你知道吗"之类的垫字
（除非该条确实需要设问开头）。

## 四、音效与配乐

- `soundscape`：只写画面内真实存在的声音（`soft cave ambience, gentle wing flaps`），
  不要写音乐
- `music`：写风格与情绪（`playful mysterious children's science music`），
  不要写具体乐器编排
- `voice`：写音色与语气（`cheerful children's science narrator`）

## 五、批量节奏

- 一批 **20 条**最合适：约 1 小时跑完，验收和返修都在可控范围
- 超过 50 条建议分批，每批单独目录 + 单独 `run_log.json`
- 同批内题材尽量分散（动物/人体/太空/日常），避免连续同类导致画面同质化

## 六、选题来源与合规边界

**可以做的**

- 公共知识点本身不受版权保护，放心用
- 从公开热榜（抖音热榜、微博热搜、B站热门、知乎热榜等）**提炼选题方向**
- 用户提供链接/截图/文案后，做**知识点提取与重新表达**
- 用官方开放平台 API（需自行注册应用并授权）取数据

**不能做的**

- 绕过平台反爬机制抓取视频
- 搬运他人视频画面、逐字照搬文案、复制剪辑结构
- 用别人的成片做二次剪辑后发布

一句话：**借鉴选题和知识点可以，搬运表达不行**。受保护的是具体表达（画面、文案、剪辑），
不是科学事实本身。

## 七、提交前校验

```bash
python scripts/validate_prompts.py --prompts prompts.json
```

检查项：必填字段、文件名格式、id 唯一性、台词长度、画面描述是否混入中文、
台词是否为空。有问题会逐条列出，改完再提交生成。

## 八、一个实测结论：单条提示词写全，模型才守规矩

对比两批真实数据（同一工作流、同一参数）：

| 批次 | 单条是否含"竖屏 + 单镜头"声明 | 校验警告 | 画面烧字幕 |
|---|---|---|---|
| 第二批 20 条 | 是 | 0 | 0 条 |
| 第三批 50 条 | 否（只写在全局说明里） | 99 条 | 4 条（8%） |

第三批的素材把 `Vertical 9:16 composition`、`One continuous shot`、`No subtitles`
都只写在文档开头的统一要求里，没有逐条进入提示词。结果是画面仍然竖屏（因为工作流
width/height 强制），但**"不要写字"的约束被稀释，8% 的片子把台词烧成了字幕**。

结论：**统一要求必须逐条落进每条提示词**，写在文档开头不算数。这也是 `validate_prompts.py`
把"缺竖屏/单镜头声明"设为警告的原因——它不是形式主义，是实测出来的质量差异。
